# GIF Search Engine 🔍

Aplicación web React para búsqueda de GIFs utilizando la API oficial de GIPHY, con diseño responsive construido con Tailwind CSS.

[![Vercel Deployment](https://img.shields.io/badge/Deployed_on-Vercel-black?style=flat&logo=vercel)](https://gif-search-engine-rho.vercel.app/)
![React](https://img.shields.io/badge/React-18.2-blue?logo=react)
![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue?logo=typescript)

## 🚀 Características Principales

-   🔎 Búsqueda en tiempo real de GIFs
-   📱 Diseño 100% responsive (mobile-first)
-   ⚡ Optimizado para rendimiento
-   🎨 Interfaz intuitiva con Tailwind CSS
-   🔐 Tipado seguro con TypeScript

## 🛠 Tecnologías

**Frontend:**

-   React.js
-   TypeScript
-   Tailwind CSS
-   Vite

**API:**

-   [GIPHY API](https://developers.giphy.com/)

## 🖥 Cómo Ejecutarlo Localmente

1. Clona el repositorio:

    ```bash
    git clone https://github.com/Corpus2k/gif-search-engine.git
    ```

2. Instala dependencias:
    ```bash
    npm install
    ```
3. Configura tu API Key de GIPHY:

-   Crea un archivo .env y agrega:
    ```env
    VITE_GIPHY_API_KEY=tu_api_key_aquí
    ```

4.  Inicia la aplicación:
    ```bash
    npm run dev
    ```
