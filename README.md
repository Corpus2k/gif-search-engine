# GIF Search App

Aplicación web para búsqueda de GIFs utilizando la API de Giphy.

<!-- ![Demo](https://ejemplo.com/) Reemplazar con tu imagen de demo si tienes -->

## Características

-   Búsqueda en tiempo real de GIFs
-   Interfaz responsive y amigable
-   Uso de la API oficial de Giphy
-   Fácil integración y personalización

## Tecnologías Utilizadas

-   HTML5
-   Tailwind
-   TypeScrit
-   React.js
-   [Giphy API](https://developers.giphy.com/)
